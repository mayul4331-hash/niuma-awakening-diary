# 时间轴设计方法

## 输入

配音 ASR 结果（mediakit `video asr-subtitles`），格式：
```json
{"subtitles": [{"start_time": 0.56, "end_time": 2.02, "subtitle_text": "永远记住一句话"}, ...]}
```

## 核心原则

1. **字幕对齐配音，不按镜头均分**。按镜头均分会导致中后段漂移 0.5–1.0 秒。
2. **开场期号标题句只配音不出字幕**。第一帧红字卡保持不动，直到第一条正文配音开始。
3. **每条字幕窗口 = [配音起 − 0.22s, 配音止 + 0.38s]**。提前 0.22s 淡入（观众先看到字再听到声，自然），延后 0.38s 淡出。
4. **镜头切换点对齐字幕切换点**。每张插画对应一条正文；镜头在该条字幕开始前 0.2–0.3s 切入，叠化 0.4s。
5. **末两句若配音一口气读完，合并为一条字幕**。如「职场讲究边界感，守住底线」。

## 步骤

### 1. 整理 ASR 段

将 ASR 段与文案逐条对应。ASR 可能把一句拆成多段（如开场长句拆成 3 段），也可能把两句合成一段。以文案为准合并/拆分：

```
ASR: 3.08-4.76 职场小白注意这几件
     4.76-6.88 上班禁区千万别碰
     6.88-8.62 踩一个都容易吃亏
→ 合并为「开场长句」，不出字幕，范围 3.08-8.62
```

### 2. 生成字幕窗口

对每条要出字幕的文案，取其配音起止（合并段取最早起、最晚止），计算：
```
sub_start = voice_start - 0.22
sub_end   = voice_end + 0.38
```

检查相邻字幕不重叠（间隔应 ≥ 0.05s）；若重叠，缩短前一条的 tail。

### 3. 生成镜头时间轴

- 镜头 0（红字卡）：0 → 第一条正文字幕开始前 0.25s
- 镜头 1..N：每条正文一个镜头，边界 = 该条字幕开始前 0.10s
- 末镜头：到成片总时长

成片总时长 = 末条配音止 + 0.4s（字幕 tail）+ 1.5–2.0s（片尾留白）。通常 34–36s。

### 4. 校验

- 每条字幕起止都在对应镜头窗口内（字幕不跨镜头切换点超过 0.2s）
- 红字卡期间（镜头 0）只有 hook 字幕，开场长句无字幕
- 叠化窗口（切换点 ±6 帧）不与字幕淡入淡出冲突（字幕带硬切，无影响）

```
0.56-2.02  永远记住一句话
3.08-8.62  开场长句（3段合并，不出字幕）

14.08-15.90 不和领导正面硬刚
16.64-18.86 也别傻傻全盘接下所有活
19.76-20.78 不谈私事

23.80-25.70 工位别摸鱼看私书
26.56-29.02 最重要！听懂领导的潜台词
31.08-33.15 职场讲究边界感，守住底线（合并）
```
